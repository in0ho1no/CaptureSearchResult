# Change Log

本拡張機能に関するすべての主要な変更は、このファイルに記録されます。

## [0.1.2]

- 検索結果が多い場合の桁区切り（カンマ）付き件数のサマリ（例: `1,234 results - 56 files`）を認識するように修正。
- サマリ行の判定を単位語（`results`/`files`/`件の結果`/`ファイル`）に基づくよう厳密化し、無関係な行の誤認識を防止。
- CRLF 改行のドキュメントで検索結果を取得できない不具合を修正（改行コードの正規化を統一）。
- 検索結果行を解析する正規表現の多項式バックトラック（ReDoS）を解消。
- ReDoS を含む正規表現を `npm run lint` および CI で事前検出するゲート（eslint-plugin-redos）を追加。

## [0.1.1]

依存ライブラリの脆弱性対応

## [0.1.0]

- VSCode の表示言語が英語の場合の検索サマリ（`n results - n files` 形式）に対応。

## [0.0.8]

- 関連環境更新の影響確認を速やかに行うことができるようworkflowにCI環境を追加
- tsconfig.json に skipLibCheck: true を追加。
  eslint-scope と @typescript-eslint の型定義の不整合によるビルドエラーを修正。

## [0.0.7]

ドキュメントの更新。

## [0.0.6]

AutoHotKey スクリプトにおけるエラー挙動を修正。

## [0.0.5]

正式リリースに向けた実装および環境の改善。

## [0.0.4]

- 出力結果にカラム（列）の見出し行を含めるように変更。
- 以下の 2 つの設定を追加。

    1. 検索結果をコピーする際に検索サマリーを含めるかどうか (True: 含む / False: 含まない)
    1. 検索結果をコピーする際にカラム見出し行を含めるかどうか (True: 含む / False: 含まない)

## [0.0.3]

出力結果に検索結果のサマリーを含めるように変更。

## [0.0.2]

検索結果の処理に使用する正規表現を修正。
検索結果の数値に含まれるコロン (:) を除外。
